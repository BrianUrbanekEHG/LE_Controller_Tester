# LE Controller Tester

A browser-based gamepad combat targeting laboratory for evaluating Last Epoch controller input, targeting, and skill behavior.

The standalone prototype runs from `docs/` with native JavaScript modules, Canvas 2D, and no build step. GitHub Pages is intended to publish at https://brianurbanekehg.github.io/LE_Controller_Tester/.

Launch locally with `python3 -m http.server 8080 --directory docs`.
